## Built
- `src/sim/arena/geometry.ts`: simple-polygon validation and bounds helpers.
- `src/sim/arena/layouts.ts`: `foundry_ring`, `foundry_cross`, `foundry_pit` layouts.
- `src/sim/arena/mutate.ts`: 22s interval mutation scheduler with 1200ms telegraph, safety predicate (`isLayoutSafe`), and blocked-mutation reporting.
- `src/sim/arena/validate.ts`: point-in-polygon, boundary distance, polygon centroid, safe-interior relocation, reachable-radius safety estimator.
- `src/sim/world.ts`: scheduler integration with `arena_mutate` telegraph/mutated/blocked/relocated events and boss-active suppression.
- `src/sim/world.ts`: entities stranded by a mutation are deterministically relocated into the new polygon; the player receives a short relocation grace window (45ms) so a shape change cannot cause a cheap death.
- `src/sim/world.ts`: axis-separated movement resolution never returns a point outside the active polygon.
- `src/render/telegraph.ts`: three coordinated telegraph cues (edge pulse, expanding decal ring, incoming-footprint fill).
- `src/main.ts`: renders all three telegraph cues; sim events carry `cue: edge_pulse+decal+audio` so the W7 audio layer can bind without sim changes.
- Tests: `tests/sim/arena.spec.ts`, `tests/sim/arena-trap.spec.ts` (relocation, unsafe-layout blocking, accelerated mutation soak), `tests/unit/telegraph.spec.ts`.

## Contracts exposed
- `stepArenaMutation(state, input)` — deterministic scheduler contract with optional `layouts` and `isLayoutSafe` predicate; returns `didTelegraph`, `didMutate`, `didBlock`.
- `isMutationSafe(polygon, minRadius)` — minimum reachable-radius gate applied before any telegraph or mutation.
- `findSafeInteriorPoint(polygon, desired, clearance)` / `isPositionSafe(...)` — relocation contract used by the simulation.
- `computeTelegraphCue(remainingMs, totalMs)` — pure three-cue telegraph description shared by renderer and tests.
